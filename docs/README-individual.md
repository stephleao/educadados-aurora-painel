## Tarefas

As 23 tarefas individuais são Issues independentes das da squad. Os **títulos não têm prefixo pessoal**, pois os cartões estão no projeto separado. Para identificar as cópias dentro do repositório compartilhado, elas têm a etiqueta `individual:Steph` e as etiquetas `solo:onda-1` a `solo:onda-6`.

[Consultar as 23 Issues individuais](https://github.com/stephleao/educadados-aurora-painel/issues?q=is%3Aopen+is%3Aissue+label%3Aindividual%3ASteph)

As Issues individuais ficam **sem assignee**, pois o quadro pessoal já define o contexto de execução. O histórico e o status são independentes das Issues da squad.

## Branch e privacidade

**Separação de arquivos não é privacidade:** o repositório é público e qualquer pessoa pode acessar as branches e Issues. A visibilidade privada do GitHub Project não torna as Issues de um repositório público privadas.

A existência deste documento somente em `steph` evita misturar orientações no `README.md` da `main`. Se a branch `steph` for incorporada à `main` via merge, os arquivos desta branch (inclusive este documento) **também podem ser incorporados**, a menos que sejam excluídos no merge ou mantidos fora dele.
