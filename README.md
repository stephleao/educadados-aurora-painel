# Painel Aurora — Bootcamp Educadados

Projeto em squad de 5 integrantes para a **Fase 01: Comercial** do desafio fictício Rede Aurora Odontologia.

**Prazo:** 07/11/2026, 23h59 (horário de Brasília). **Início do plano:** 04/11/2026.

## Objetivo
Relatório Power BI de **até duas páginas** com vendas em valor e quantidade, metas e percentuais de atingimento nos cortes: rede, filial, cidade, vendedor, profissional, grupo de serviço e serviço. Itens sem meta devem apresentar **“sem meta”**.
